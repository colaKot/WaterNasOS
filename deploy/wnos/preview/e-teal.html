一台自己的 NAS，能做什么

每一项功能都是独立的 App：有自己的图标、独立页面栈和独立的服务端 API。

照照片管理

时间线、自建相册、智能相册、照片合集；人脸与场景识别、相似照片、GPS 补录、足迹地图、那年今日、回收站。按用户隔离。

影影视库

电影 / 电视剧 / 图片 / 混合媒体多库管理；自然序排序、瀑布流与网格视图；H.264 / HEVC / AV1 转码、响度归一化。

音音乐与图书馆

歌曲、专辑、歌手、播放列表、合集与收藏，内置全屏播放器；EPUB / MOBI / AZW3 / PDF / TXT 即点即读。

件文件与分享

文件浏览、上传下载、AES 加密空间；WebDAV / FTP / SFTP 分享磁盘，远程挂载网络磁盘，查看系统监控。

同多端同步

Windows 同步端与主端共用同一引擎：双向 / 仅下载 / 仅上传与过滤规则；手机相册自动备份，内容 MD5 去重。

权进阶与权限

Transmission BT 下载、Docker 管理、远程终端；子账号权限体系：应用级白名单 + 路径级细粒度权限。
