Windows NAS · 服务端

一台 Windows 电脑，就是你的 NAS

WaterNasOS 属于 Windows NAS 范畴：服务端常驻运行在 Windows 上，不用刷机、不用折腾群晖，一台普通电脑就能变成全家共用的私有云存储。

它是什么

服务端（electron_server）是整套系统的心脏，基于 Electron + Express 实现，常驻 Windows x64 运行， 负责照片与影视索引、ffmpeg 转码、AI 识别、同步通道和全部 API。桌面端、安卓、TV 与网页端，连的都是同一个它。

数据只在你自己家

所有数据落在本地磁盘与 SQLite，不经过任何公有云；多用户账号、相册按用户隔离、AES 加密空间全部在本地完成。 对外拔掉网线，内网照用不误。

下载服务端

GitHub Releases 获取 Windows x64 服务端包（v1.1.0），第三方依赖与识别模型已内置，解压即用。

一键启动

双击运行、常驻托盘，局域网内的其他设备即可发现并连接这台 Windows NAS。

各端连接

桌面端、安卓、TV 与网页端填写同一个服务端地址，照片影音实时同步、各看各的。

建库开始用

添加照片与影视目录、创建子账号分配权限，一套 Windows NAS 就正式服役了。

核心能力

一台自己的 NAS，能做什么

每一项功能都是独立的 App：有自己的图标、独立页面栈和独立的服务端 API，可在设置中隐藏或重新排序。

照片管理

按用户隔离的照片库

时间线、自建相册、智能相册、照片合集；人脸与场景识别、相似照片、GPS 补录、足迹地图、那年今日、回收站。 每个人只看自己的照片。

音乐与图书

播放器 + 阅读器

歌曲、专辑、歌手、播放列表与收藏，内置全屏播放器（动态歌词、后台播放）；EPUB / MOBI / AZW3 / PDF / TXT 即点即读。

文件与分享

把磁盘分享出去

文件浏览、上传下载、加密空间（AES）；通过 WebDAV / FTP / SFTP 等协议把磁盘分享出去，远程挂载网络磁盘，随时查看系统监控与后台任务。

多端同步

三种同步方向

Windows 独立同步客户端与主客户端共用同一套引擎；手机相册自动备份，按「大小 + 内容 MD5」去重。

进阶与权限

子账号细粒度权限

Transmission BT 下载、Docker 管理、远程终端；子账号应用级白名单 + 路径级细粒度权限。

全端覆盖

同一套服务端，四种终端

手机、电脑、电视与网页端共用同一套服务端与数据，各端专注自己的场景。

服

Windows 服务端

常驻运行的服务核心，提供全部 API、任务队列与存储管理，是整套系统的心脏。

桌

Windows 桌面端 / 同步端

WaterNasClient 主客户端 + WaterNasSync 独立同步端，一个管全家桶应用，一个专心同步目录。

端

Android 三端

主端、相册端、音乐端三个 APK 各自独立，图标与启动模式分离，按需安装。

视

TV 与网页端

Android TV / Apple TV 大屏播放；浏览器直接访问网页端，零安装即可管理。
