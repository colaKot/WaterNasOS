## 1）中文显示成「方块里一个 X」

**根因**：Flutter Web（CanvasKit）不带中日韩字形。缺字形时引擎会去
`fontFallbackBaseUrl`（默认 `https://fonts.gstatic.com/s/`）现拉 Noto 的分片 woff2。
NAS 在内网 / 客户端连不上 gstatic ⇒ 拉不到 ⇒ 豆腐块。引擎还有一层熔断：
连续 10 次失败且一次都没成功，就整场会话禁用回退服务（日志 `Could not find a set of
Noto fonts...` / `Disabling service for this session`）。

**修法**（不打包字体，不写死路径）：

| 位置 | 改动 |
| --- | --- |
| `flutter_client/web/fonts_fallback/s/**` | 227 个 Noto 分片镜像（7.8 MB），路径与 SDK 的 `font_fallback_data.dart` 一字不差 |
| `flutter_client/web/index.html` | 给 `_flutter.loader.load()` 塞 `config.fontFallbackBaseUrl = 'fonts_fallback/s/'`（见下） |
| `tool/fetch_fallback_fonts.py` | 从当前 SDK 里抽 URL 重新镜像；`--clean` 全量、默认只补缺 |
| `tool/_sync_web_build.py` | `listfiles` 改成**递归**（原来只同步顶层文件，字体永远进不了 dist） |

镜像了这些族：`notosanssc`（101）/ `notosanstc`（105）/ `notocoloremoji`（12）/
`notosanssymbols2`（6）/ `notosanssymbols` / `notosans` / `roboto/v32`。

### ⚠️ 为什么不是 `window.flutterConfiguration`

一开始按老文档写了 `window.flutterConfiguration = { fontFallbackBaseUrl: ... }`，
**实测无效**：引擎照样去 `fonts.gstatic.com` 拉 Noto（用无头 Chrome 抓 resource timing +
屏蔽 gstatic 截图验证过，屏蔽后整页中文变方块）。Flutter 3.x 的 bootstrap 已经不看那个全局，
配置只能走 `_flutter.loader.load({ config })`。

而 `flutter_bootstrap.js` 自己会立刻调一次 `_flutter.loader.load()`（没带 config），
所以 `index.html` 里先占住 `window._flutter`（给它装 `loader` 的 setter），
在真实 loader 赋值的瞬间把 `load()` 包一层补上 config。改完实测：
Noto 请求全部变成 `http://<nas>/fonts_fallback/s/...`。

⚠️ **升级 Flutter SDK 后必须 `python tool/fetch_fallback_fonts.py --clean`**：
URL 里带 `<family>/<version>/<内容哈希>.<n>.woff2`，SDK 一换旧文件名全失效 ⇒ 又变豆腐块。

## 3）人生章节：可翻的书（一页 = 一年里的一天）

**服务端**（新接口 `POST /api/photo/app_ai/chapter_book`，只读、按 uid 隔离）：

- `appAiService.chapterBook({year, per_day=24, max_days=366})`
  → `{year, days:[{date, photo_count, photos[≤per_day], scenes, activities, people,
  place, note, title}], total_days, truncated}`
- 一次取该年 `type=1` 的行（按 `original_time` 倒序，`row_limit` 默认 8000）→ 按
  `original_date` 分组 → 天倒序（最近在前）。
- 标签一次查完：全年的 file_hash 丢给 `_labelsOfHashes`（6000 张封顶）。
- 地点走 `photoMapService.getLocationStr({dbGeo, locale}, geohash5, lat, lng)`，
  同一 geohash5 只查一次、最多 60 个格。
- `note` = 已确认记忆（`photo_memories.<uid>`）里 `key` 前缀为该天、`confirm_time` 最新的一条。

**前端** `recall/view/photo_chapter_book_view.dart`：

- 记忆页点章节卡 → 不再 `openSinglePhoto(封面)`，而是进这本书（`_bookYear` 状态切换）。
- 双页对开：左页「行影集 · @year 年的影像」+ 大号 `MM / DD` + 1 大 2 小图 + 本日精选；
  右页「@date · 这一天的故事」+ 影像日记 + 地点 + 文字 + 标签 + 这一天的片刻。
- 文字：有已确认记忆的 `note` 就用它；没有就按真实标签拼一句
  （`photo_book_story_place/plain/scenes/acts/people/end`），**不编故事**。
- 翻页：底部「上一页 / 下一页」、键盘 `←/→`、`PageUp/PageDown`、`Home/End`、`ESC` 返回。
- 点任意照片 → `openPhotoImages(当天整组, index)`，看图器自带左右滑/左右键。
- 书页高度 = `宽 × 0.42`（430~660），内容超出在**页内**滚动 —— 不用 IntrinsicHeight，
  否则长备注会把整本书撑成一条长条。
