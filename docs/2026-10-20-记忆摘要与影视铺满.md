## 1）记忆列表不再写「已确认的记忆」

**问题**：`我的记忆` 卡片下方那个框里，`note` 为空时固定显示
`photo_memory_saved_note`（"已确认的记忆，点开可以再看一遍"）——
既是废话，又把卡片占得满满的。

**现在**：框里给一句真实摘要 `地点 · 干了什么 · N 张`，例如
`广州 天河公园 · 散步 · 32 张`。全部来自真实标签，**不编故事**。

| 位置 | 改动 |
| --- | --- |
| `appAiService._attachMemoryPlaces()` | 记忆的 key 就是 `day|geohash5`，拿格子去 geonames 反查地名，补 `place` 字段；同格子只查一次，最多 120 格 |
| `appAiController.memories` | 补 `params.dbGeo` + `params.locale`（原来只传 uid ⇒ `place` 恒为空） |
| `photo_memory_view._summaryOf()` | 活动标签优先，没有就退回场景，再拼张数；用户自己写过 note 时优先用 note |
| `photo_memory_detail_view._noteText` | 详情页的「这段记忆」框同样在 note 为空时显示摘要 |
| 卡片网格 | `mainAxisExtent` 312 → 296（摘要变一行短句，不用再留大白框） |

## 2）地名只显示一种语言

`photoMapService.getLocationStr()` 原来在本地名 ≠ 英文名时返回
`` `${localName} ${enName}` `` ⇒ 界面上出现「广州 Guangzhou」。
改成 `localName || enName`：有本地名（中文）就只显示中文，没有才退回英文名。
所有走 `getLocationStr` 的地方（记忆、人生章节、图片属性、时间轴筛选）一起生效。

## 4）影视全屏：画面铺满 + 字幕贴画面

**现象**（铁柱手机端）：全屏后四周仍有黑边，画面明显偏小；字幕落在黑边里。

**原因**：播放画面一直按「原始比例 contain」居中，Android Media3 的 `PlayerView`
默认也是 `RESIZE_MODE_FIT` ⇒ 画面按比例缩到中间，四周全是黑。

**改法**：

| 层 | 改动 |
| --- | --- |
| 状态 | `PlayerController.isVideoCover`（默认 **true = 铺满**），本机 `SharedPreferences` 记住；`openPlaylist` 时 `loadVideoScaleMode()` 恢复 |
| Android 原生 | `Media3PlayerSession.setResizeMode()` → `PlayerView.resizeMode = RESIZE_MODE_ZOOM`（铺满裁边）/ `FIT`（适应）；`attachPlayerView` 时也套一次，换视图不丢 |
| 通道 | `NascabPlaybackMethodHandler` 新增 `setResizeMode`；`Media3PlaybackEngine.setVideoResizeMode()` 转发 |
| Flutter 画面 | `PlaybackVideoSurface(cover: ...)`：FVP 走 `FittedBox(BoxFit.cover)` + `ClipRect`；Media3 交给原生 |
| 字幕 | `transcodeSubtitleBottomPadding()` 按真实宽高比算下方黑边高度，把 VTT 字幕整体抬到**画面底边以上**；铺满时不抬 |
| 真实宽高比 | 原生事件新增 `videoWidth/videoHeight` ⇒ `PlaybackValue.aspectRatio`（原来 Media3 恒 16:9） |
| 切换入口 | 手机：`更多 → 画面比例`；桌面：底栏新增一个比例按钮。切换后 toast 提示当前模式 |

字幕仍然是**叠在画面上**的（原生 `SubtitleView` / 客户端 VTT 叠层都在画面内），没有单独的黑条区域。
